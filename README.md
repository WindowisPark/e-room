# 플래노바 (Planova)

> 학창시절부터 취업까지, 당신의 모든 계획은 플래노바가

---

## 플래노바는?

PDF로 공부하고, AI 튜터에게 질문하고, 이력서·자소서까지 한 곳에서 준비하는 **올인원 학습·취업 플랫폼**입니다.

기존 v1(팀 협업·게이미피케이션·결제 등)에서 핵심 가치만 남기고, **학습 → 취업 준비**라는 하나의 여정에 집중하도록 v2로 재설계했습니다.

---

## 이런 분들을 위해 만들었어요

- PDF 교재로 공부하면서 AI가 요약·문제를 만들어줬으면 하는 **학생**
- 이력서·자소서 작성을 한 곳에서 관리하고 싶은 **취업 준비생**
- 관심 기업 채용공고를 모아두고 AI 분석까지 받고 싶은 **구직자**

---

## 주요 기능

### 학습

| 기능 | 설명 |
|------|------|
| PDF 학습 | PDF 업로드 후 AI가 자동 요약, 핵심 문제 생성, Q&A 응답 |
| AI 튜터 | 업로드한 PDF 내용을 기반으로 1:1 질의응답 |
| 캘린더 | AI 추천 학습 일정 + 직접 일정 관리 |

### 커리어

| 기능 | 설명 |
|------|------|
| 이력서 | 학력·경력·자격증 등 항목별 관리, PDF 내보내기 |
| 기업 조사 | 채용공고 URL 입력 → AI가 기업 정보·자격 요건 분석 |
| 자소서 | 문항별 작성 + AI 초안 생성으로 빠르게 시작 |

## 기술 스택

| 영역 | 기술 |
|------|------|
| Frontend | Vue 3, Vite |
| Backend | FastAPI, PostgreSQL, Redis |
| AI | LangGraph + Gemini 2.5 Flash, ChromaDB |
| 인증 | 카카오 로그인, 이메일 로그인 (JWT) |
| 배포 | Railway + Cloudflare Pages |

## v1 → v2 변경 요약

| | v1 | v2 |
|--|----|----|
| 콘셉트 | PDF 팀 협업 플랫폼 | 학습·취업 올인원 플랫폼 |
| 핵심 | 팀스페이스, 게이미피케이션, 결제 | PDF AI 학습, 이력서, 자소서, 기업조사 |
| AI | 없음 | Gemini 기반 요약·QA·문제생성·자소서 초안 |
| 과금 | 유료 구독 | 무료 |
